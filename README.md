# Alessandro Ivashkevich - Portfolio Website 🚀

Personal portfolio website showcasing my journey as a Data Scientist and Business Analytics enthusiast.

🌐 **Live Site:** [alessandroiva.github.io](https://alessandroiva.github.io)

## About

This is my personal portfolio website built with pure HTML, CSS, and JavaScript. It features a modern, minimalist dark theme design with full multilingual support.

## ✨ Features

- **Multilingual Support**: Available in English, French, Italian, and Russian
- **Responsive Design**: Fully responsive layout that works on all devices
- **Dark Theme**: Modern dark UI with smooth transitions
- **Interactive Elements**: Hover effects and smooth scrolling
- **Sections Include**:
  - About Me
  - Professional Experience
  - Skills & Expertise
  - Featured Projects
  - Contact Information

## 🛠️ Technologies Used

- HTML5
- CSS3 (with custom properties and flexbox/grid)
- Vanilla JavaScript
- SVG for favicon

## 🎨 Design Features

- **Color Scheme**: Dark background (#0a0a0a) with light text
- **Typography**: System fonts for optimal performance
- **Layout**: Mobile-first responsive design
- **Animations**: Smooth transitions and hover effects

## 🌍 Language Versions

The website supports four languages:
- 🇬🇧 English (EN)
- 🇫🇷 French (FR)
- 🇮🇹 Italian (IT)
- 🇷🇺 Russian (RU)

Language switching is handled dynamically via JavaScript without page reloads.

## 📱 Responsive Breakpoints

- Desktop: > 968px
- Tablet: 480px - 968px
- Mobile: < 480px

## 🚀 Deployment

This site is hosted on GitHub Pages and automatically deploys from the `main` branch.

To deploy your own version:
1. Fork this repository
2. Go to Settings → Pages
3. Select the `main` branch as source
4. Your site will be live at `https://yourusername.github.io`
